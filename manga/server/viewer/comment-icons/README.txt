Outlines with a two-colour gradient, drawn directly for this template from simple
shapes (star, moon, drop, leaf, flower, cloud, heart, sparkle). No brand mark,
character or third-party icon library was used. Readers choose one of them beside
their anonymous comments. The site owner can add more from the admin (SVG files
are checked by lib/log-svg.php and served only as pictures).
