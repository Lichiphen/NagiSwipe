NagiSeries は、個人サイトのための小さな道具のシリーズです。画像を大きく見せる NagiSwipe、漫画を読んでもらう NagiManga、文章・画像・漫画を投稿できる NagiLog の 3 つがあります。どれもデータベースや外部サービスを使わず、自分のサイトに置くだけで動きます。

NagiSwipe を使う NagiManga・NagiLog を設置する GitHub

3 つのツール#

NagiSwipe

画像ポップアップ・ギャラリー

  • JS と CSS を読み込むだけで、ページの画像リンクを自動でギャラリーにします
  • スワイプ、ピンチズーム、ダブルタップ、キャプション
  • てがろぐは管理画面の設定だけで使えます
ドキュメントデモ

NagiManga

漫画ビューアーと管理画面

  • タグを 1 つ貼るだけで、クリックすると漫画ビューアーが開きます
  • 右から左・見開き・縦読み（ページ漫画／ウェブトゥーン）
  • EPUB からの取り込み、パスワード付きの限定公開、ZIP でのバックアップ
ドキュメントデモ

NagiLog

個人用LOG（データベース不要）

  • 文章・画像・漫画を、自分のサイトへスマホからでも投稿できます
  • 動画と音声：波形のプレーヤー、つなぎ目のないループ、ジャケットとループ位置
  • カテゴリ、ハッシュタグ、検索、6 種類のデザイン、RSS、閲覧注意
ドキュメントデモ

どれを使えばいい？#

やりたいこと使うもの必要なもの
ブログやてがろぐの画像を、スマホでも気持ちよく拡大して見せたいNagiSwipeJS と CSS の 2 ファイル（jsDelivr から読み込めます）
自分のサイトで漫画を読んでもらいたいNagiMangaPHP 8.1 以上のサーバー。管理画面を使わず、FTP だけで置くこともできます
文章・絵・漫画を、自分のサイトに気軽に投稿したいNagiLogNagiManga と同じ設置（追加の準備はいりません）
NagiManga を使い続けて大丈夫か知りたい手引き開発者でない方向けに、メリット・デメリットとデータの取り出し方をまとめています

3 つの関係#

  1. NagiSwipe は単独で使えるライブラリです。NagiManga と NagiLog の中でも、画像の拡大に使っています（配布 ZIP に同梱しています）。
  2. NagiManga を設置すると、作品を管理する画面と、読者向けのビューアーが使えます。
  3. NagiLog は NagiManga に含まれています。同じ nagimanga フォルダ、同じログインで、LOG の公開サイトも動きます。

入手する#

  • NagiSwipe: jsDelivr の URL を貼るだけです。導入方法に、いつも最新版の URL を載せています。
  • NagiManga・NagiLog: リリースページの nagimanga-vX.Y.Z.zip をダウンロードして、サーバーにアップロードします。手順は管理画面（PHP）を使うにあります。
  • ソースコード: GitHub / GitLab（同じ内容です）
